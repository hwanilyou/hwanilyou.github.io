OddOne Puzzle Studio — Privacy Policy

Last updated: 2026-09-30

OddOne Puzzle Studio ("the app") is a private desktop tool operated by an individual creator, Hwanil Yu, to manage their own YouTube channel. It is not offered to or used by anyone else.

What the app accesses

Through the YouTube API Services, and only after the channel owner signs in with Google and grants permission, the app:

  • uploads videos to the owner's own channel,
  • reads the processing and privacy status of those videos and updates their privacy status,
  • reads YouTube Analytics reports (views, watch time, subscribers gained/lost) for the owner's own channel.

    • The app does not access other people's channels, accounts, or personal data.

    How data is used and stored

  • API data (video IDs, status, analytics numbers) is used only to operate and evaluate the owner's own channel.
  • It is stored only on the owner's computer (a local database and report files). It is not sold, shared with, or disclosed to any third party.
  • OAuth tokens are stored locally in a separate folder and are never written to logs.

    • Revoking access and deleting data

  • Access can be revoked at any time at https://myaccount.google.com/permissions (Google Account → Security → Third-party apps).
  • Locally stored API data is deleted when access is revoked or on the owner's request.
